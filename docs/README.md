# AugmentiQ Docs

| Folder | Audience | Git |
|---|---|---|
| `public/` | Customers — install guides, architecture, security | **Committed & pushed** (this is a public repo) |
| `internal/` | Us — launch plan, decision log, research, design specs, bug log | **Gitignored — never commit or push** |

**Golden rule:** before any commit, `git status` must not show anything under `docs/internal/` as staged or tracked.
