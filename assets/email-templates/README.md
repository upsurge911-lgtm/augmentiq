# DSR Email Templates

Plain-text starting points for the `/augmentiq dsr` flow's user-facing
notifications. The agent fills `<VALUES>` and adjusts the regulatory
basis to the user's jurisdiction (the templates cite GDPR articles as
the default). Not legal advice — the operator signs off before sending.

| File | When |
|---|---|
| `dsr-acknowledgment.md` | On receipt of a data subject request |
| `dsr-completion.md` | On fulfillment |
